# Mac desktop preview and website downloads

The website exposes **Download for Mac** on the homepage and in the Health and
Research chat headers. `/download` shows the actual app, the supported platform,
installation instructions, model prerequisites, data boundaries and a versioned
GitHub Releases download. It makes no performance comparison.

## Release artifact

`lib/desktop-release.json` is generated by `cd desktop && npm run archive` after
packaging. It records the exact ZIP URL, byte count and SHA-256 used by the page.
The ZIP contains the app and its runtime notices, with no user history, model
credentials, `.env` files or development dependency directories. Publish the ZIP
and its `.sha256` companion to the named release before deploying that manifest.

This is a free local Apple Silicon preview, macOS 13+. It is ad-hoc signed and
**not notarized by Apple**. The download page discloses this before the button is
used and links Apple's instructions. The installed Codex CLI and the user's own
eligible ChatGPT access are required for chat. Python 3 is needed for the local
terminal; Claude Code is optional and retains its own login. The website does not
host subscription inference or sell provider access.

## Desktop changes in 0.2.0

- Rename projects and investigations without renaming source folders.
- Archive and restore work, retaining chats, evidence and handoffs.
- Remove archived app history only after native confirmation. Project files,
  reports, exports and original Codex history remain separate.
- Browse and read saved Markdown reports in Files; refresh the file inventory.
- Preserve old workspace data through defaulted archive fields and atomic writes.
  A background save waits for a pending management change to finish.
- Include bundled JavaScript license notices and Electron/Chromium notices.

## Verified before publishing

- 34 desktop unit tests, including legacy state loading, archive/restore,
  cross-project isolation, confirmed removal, disk failure and concurrent saving.
- Native app: dataset statistics, memory/restart, project management, report
  preview, real terminal, 800/1000/1400 layouts in both themes, ChatGPT sign-in
  and the model catalog. The packaged app completed a synthetic research task.
- Full web verification: lint, TypeScript, 687 tests, 59 UI tests, 44 offline
  evaluation checks and production build. Live scientific evals are separate.
- Isolated-browser checks at 390 and 1400 pixels: homepage, Health chat,
  Research chat, install page, app screenshot, release metadata and no overflow.
- The release archive passes ZIP integrity and macOS signature verification.

After deployment, run `node scripts/smoke-download.mjs --url=https://www.nutritiscan.com --verify-download`
from `desktop/`. It clicks the public download button and checks the downloaded
file's name, size and SHA-256 against the manifest.

Researcher review is still required. This release does not add clinical
validation, live instrument control, formal evidence grading or automatic web
and desktop conversation synchronization. Other unfinished pilot work stays
in its own worktree and is not included in this release.
