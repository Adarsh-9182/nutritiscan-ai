# Sample biology workspace

This workspace contains fictional instrument readings for testing NutritiScan.
It is not an experiment and provides no evidence about any disease or treatment.

`instrument-readings.csv` has six synthetic observations. The column `signal_au`
contains arbitrary units. The mean across all six observations is 107.8333333333.
Group differences in this tiny fictional file do not establish efficacy, causation,
measurement validity or biological relevance.

PubMed or ClinicalTrials.gov. Those searches are independent of this fictional file.
